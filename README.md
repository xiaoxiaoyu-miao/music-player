# 人生生死 · 沉浸式滚动歌词播放器

一个为《人生生死》（小小羽 / 专辑《青春的那些事》）定制的单曲音乐播放器，
带逐行滚动歌词、封面取色和**中文翻译 / 罗马音**双语副行切换。

## 数据来源（全部从音频文件里自动提取）

音频文件是 WAV 容器，尾部带有 `id3 ` 与 `LIST` 块：

| 文件 | 内嵌内容 |
| --- | --- |
| `/storage/emulated/0/Movies/20336.wav` | 音频 + 封面(`APIC`) + 日文歌词与**罗马音**(`USLT`) |
| `/storage/emulated/0/Movies/20337.wav` | 音频 + 封面(`APIC`) + 日文歌词与**中文翻译**(`USLT`) |
| `/storage/emulated/0/20337.wav` | 与 `Movies/20336.wav` 内容相同 |

三份文件的音频数据 SHA-256 完全一致（同一版母带）。构建脚本分别解析两个
`USLT` 帧，按时间戳对齐后合并成三栏数据，写入 `assets/data.js`：

```js
{ t: 1.14, jp: "人生は反抗期。", ro: "jinsei wa hankouki", zh: "人生是反抗期。" }
```

封面取自 `APIC` 帧（1080×1080 JPEG），已导出为 `assets/cover.jpg`（原图）与
`assets/cover-600.jpg`（网页用）。

元数据：`作词 小小羽 / 作曲 suno / 2026.10.3`。

## 功能

- **滚动歌词**：当前行居中高亮并带光晕，前后行渐隐、轻微缩小与模糊。
- **副行切换**：`中文` / `罗马音` / `关闭` 三种模式（键盘 `T` 循环切换）。
- **点击歌词跳转**：点任意一行立即从该句开始播放。
- **手动浏览**：手指或滚轮往上滑可以自由查看歌词，此时自动跟随暂停并浮出「↓ 回到当前」按钮。
- **封面取色**：用 Canvas 采样封面自动提取主色，驱动整体渐变与控件高亮。
- **双视图**：歌词视图 / 封面视图（黑胶唱片播放时缓慢旋转）。宽屏下自动变成左右双栏。
- **音质切换**：右上角立方体按钮在 `MP3 320kbps` 与 `WAV 无损原音` 之间切换。
- **其他**：进度条与音量条可拖动、单曲循环、静音、播放进度本地记忆、锁屏媒体控制（Media Session API）。
- **键盘快捷键**：空格 播放/暂停，`←` `→` 快退/快进，`↑` `↓` 音量，`L` 循环，`M` 静音，`T` 译文，`C` 视图。

## 文件结构

```
.
├── index.html                  # 页面（内联 CSS/JS，无外部依赖）
└── assets
    ├── data.js                 # 由两份 WAV 的 ID3 自动生成的曲目与歌词数据
    ├── cover.jpg               # 1080×1080 原始封面
    ├── cover-600.jpg           # 网页用封面
    ├── favicon.jpg
    └── audio
        ├── 20337.mp3           # MP3 320 kbps（默认音源）
        └── 20337.wav           # 原始无损音源
```

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

> 注意：直接以 `file://` 打开时浏览器可能因本地文件策略拒绝加载音频，建议用上面的
> 方式起一个本地服务器。

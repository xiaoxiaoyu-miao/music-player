# 沉浸式滚动歌词音乐播放器

一个带逐行滚动歌词、封面取色、双语副行切换的网页音乐播放器。

## 曲目

| # | 曲目 | 艺人 | 专辑 | 时长 | 音源 | 副行 |
| - | --- | --- | --- | --- | --- | --- |
| 1 | 人生生死 | 小小羽 | 青春的那些事 | 1:55 | MP3 320k + WAV 无损 | 中文翻译 / 罗马音 |
| 2 | 寂 | 三爪x | 致青春的那些经历 | 3:58 | MP3 320k | 无（歌词本身为中文） |

## 数据全部来自音频文件内嵌标签

没有使用任何外部歌词源，歌词与封面都是从音频文件的 ID3 里提取的：

```
/storage/emulated/0/Movies/20336.wav            音频 + 封面(APIC) + 日文/罗马音(USLT)
/storage/emulated/0/Movies/20337.wav            音频 + 封面(APIC) + 日文/中文翻译(USLT)
/storage/emulated/0/Download/.../三爪x - 寂.mp3   音频 + 封面(APIC) + 中文歌词(USLT)
```

- 前两首 WAV 的**音频数据 SHA-256 完全一致**（同一版母带），差别只在 `USLT` 歌词帧。
  构建脚本按时间戳把两者的歌词合并成三栏：`{ t, text, ro, zh }`。
- WAV 容器里 ID3 存在 `id3 ` chunk 中（在 `data` chunk 之后），另有一个 `LIST/INFO` chunk
  存放 `IART / INAM / IPRD` 等 GBK 编码的文字标签。
- `assets/data.js` 由脚本生成，请勿手改。

## 功能

- **滚动歌词**：当前行居中高亮带光晕，前后行渐隐、轻微缩小与模糊。
- **点击歌词跳转**：点任意一行立即从该句开始播放。高亮以「请求位置」为准驱动，
  不依赖回读 `currentTime`（浏览器在 seek 落地前会读回旧值，会导致跳回开头）。
- **副行切换**：`中文` / `罗马音` / `关`（键盘 `T`）。没有副行的曲目会自动隐藏该开关。
- **手动浏览**：手指或滚轮上滑可自由查看歌词，此时暂停跟随并浮出「↓ 回到当前」。
- **封面取色**：Canvas 采样封面自动提取主色，驱动整体渐变、控件高亮与唱片辉光，切歌自动换色。
- **双视图**：歌词 / 封面（黑胶唱片播放时缓慢旋转）。宽屏自动变左右双栏。
- **播放列表**：点顶部封面或右下角列表按钮展开，可切歌；支持列表循环 / 单曲循环 / 随机播放。
- **音质切换**：曲目有多种音源时显示（第一首可在 MP3 320k 与 WAV 无损间切换）。
- **其他**：进度条与音量条可拖动、静音、播放进度与设置本地记忆、锁屏媒体控制（Media Session API）。
- **快捷键**：

  | 键 | 作用 | 键 | 作用 |
  | --- | --- | --- | --- |
  | `空格` | 播放 / 暂停 | `P` / `N` | 上一首 / 下一首 |
  | `←` `→` | 快退 / 快进 5 秒 | `L` | 循环模式 |
  | `↑` `↓` | 音量 | `T` | 副行切换 |
  | `Tab` | 播放列表 | `C` | 切换视图 |

## 文件结构

```
.
├── index.html                  # 页面（内联 CSS/JS，无框架、无 CDN）
└── assets
    ├── data.js                 # 由音频内嵌 ID3 自动生成的曲目与歌词数据
    ├── favicon.jpg
    ├── covers
    │   ├── jinsei.jpg / jinsei-600.jpg
    │   └── ji.jpg / ji-600.jpg
    └── audio
        ├── jinsei.mp3          # 人生生死 · MP3 320kbps
        ├── jinsei.wav          # 人生生死 · 原始 WAV 无损
        └── ji.mp3              # 寂 · MP3 320kbps
```

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

> 直接以 `file://` 打开时浏览器可能因本地文件策略拒绝加载音频，建议用上面的方式起本地服务器。

## 数据全部来自音频文件内嵌标签

没有使用任何外部歌词源。歌词取自 `USLT` 帧，封面取自 `APIC` 帧。

```
/storage/emulated/0/Movies/20336.wav      音频 + 封面 + 日文/罗马音(USLT)
/storage/emulated/0/Movies/20337.wav      音频 + 封面 + 日文/中文翻译(USLT)
/storage/emulated/0/Download/netease/cloudmusic/Music/
    三爪x - 寂.mp3 / ヨルシカ - だから僕は音楽を辞めた.mp3 / 宵崎奏 - 命に嫌われている.mp3
    v是兔子wishtoday - 流水.mp3 / v是兔子wishtoday - 一个循环，冬天结束的时候.mp3
```

两处需要特别处理的地方：

**1. 两版 WAV 的歌词合并** —— 20336 与 20337 的音频数据 SHA-256 完全一致（同一版母带），
差别只在 `USLT` 帧。脚本按时间戳把两版合并成三栏：`{ t, text, ro, zh }`。
另外 WAV 的 ID3 存放在 `data` chunk 之后的 `id3 ` chunk 里，还有一个 `LIST/INFO`
chunk 存放 GBK 编码的 `IART / INAM / IPRD`。

**2. 日文原文与中文译文同行的拆分** —— 网易云部分歌曲把译文直接接在原文后面
（如 `[00:01.08]考えたってわからないし 想过之后依然搞不懂`）。脚本按**假名边界**拆分：
只在空格处切，取第一个「其后完全不含假名」的空格位置。这比按空格或标点硬切更可靠，
既不会把 `そうか 僕だけが` 这种含空格的真日文行误切，也不会把 `「…」` 的右引号切到译文里。

`assets/data.js` 由脚本生成，请勿手改。

## 功能

- **滚动歌词**：当前行居中高亮带光晕，前后行渐隐、轻微缩小与模糊。
- **点击歌词跳转**：点任意一行立即从该句开始播放。高亮以「请求位置」为准驱动，
  不依赖回读 `currentTime`（浏览器在 seek 落地前会读回旧值，会导致跳回开头），
  并带 seek 落地确认与 1.5 秒兜底。
- **副行切换**：按当前曲目**实际拥有的**副行类型自适应 —— 有罗马音的才显示「罗马音」按钮，
  没有副行的曲目整个开关隐藏（键盘 `T` 在可用项之间循环）。
- **手动浏览**：手指或滚轮上滑可自由查看歌词，此时暂停跟随并浮出「↓ 回到当前」。
- **封面取色**：Canvas 采样封面自动提取主色，驱动渐变、控件与唱片辉光，切歌自动换色。
- **双视图**：歌词 / 封面（黑胶唱片播放时缓慢旋转）。宽屏自动变左右双栏。
- **播放列表**：点顶部封面或右下角列表按钮展开；支持列表循环 / 单曲循环 / 随机播放。
- **音质切换**：曲目有多种音源时才显示（第 1 首可在 MP3 320k 与 WAV 无损间切换）。
- **其他**：进度条与音量条可拖动、静音、进度与设置本地记忆、锁屏媒体控制（Media Session API）。
- **快捷键**：

  | 键 | 作用 | 键 | 作用 |
  | --- | --- | --- | --- |
  | `空格` | 播放 / 暂停 | `P` / `N` | 上一首 / 下一首 |
  | `←` `→` | 快退 / 快进 5 秒 | `L` | 循环模式 |
  | `↑` `↓` | 音量 | `T` | 副行切换 |
  | `Tab` | 播放列表 | `C` | 切换视图 |

## 本地预览

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

> 直接以 `file://` 打开时浏览器会因本地文件策略拒绝加载音频（表现为点歌词跳不动），
> 必须用上面的方式起一个本地服务器。
